# ぶらりにっぽん

日本中をのんびり移動しながら、**地名・道路のつながり・土地の位置関係**を覚えるためのスマホ向けブラウザゲームです。
勝ち負けやミッションはありません。好きな場所から、好きな乗り物で、好きな速さで移動するだけのゲームです。

## 遊び方

1. **出発地を選ぶ**：日本地図をタップするか、「東京駅」「大阪・梅田」などのおすすめ地点から選びます。
2. **移動モードを選ぶ**：徒歩／ランニング／自転車／車（乗用車・軽自動車・スポーツカー・トラック・バス）／飛行機
3. **倍速を選ぶ**：×1（実際の速さ）から ×10,000 まで。
   - 例：飛行機（巡航 約900km/h）で東京→那覇（約1,550km）は ×1 だと約1時間40分、×1,000 だと約6秒です。
4. **目的地（任意）**：設定すると、目的地の方角と残りの距離が表示されます。
5. **出発！** アクセル・ブレーキ・ハンドル（◀ ▶）だけで操作できます。

### 操作

| ボタン | 動き |
| --- | --- |
| アクセル | 加速 |
| ブレーキ | 減速。止まってから長押しするとバック |
| ◀ ▶ | ハンドル |
| 道路アシスト | ON にすると、ハンドルを触っていない間は道なりに自動で進みます（交差点はまっすぐ進み、曲がりたい時だけハンドルを切ります） |
| クルーズ | 今の速度を保ちます（アクセルを押し続けなくてよい） |
| ×1 ボタン | 倍速を ×1 → ×10 → ×100 → ×1,000 → ×10,000 と切り替え |
| ＋／－／👁 | 拡大・縮小・視点切替（後方／見下ろし／真上の地図） |
| ☰ | メニュー（倍速の細かい調整、乗り物の乗り換え、表示の切り替え、出発地の選び直し） |

PC ではキーボードでも操作できます（↑ アクセル／↓ ブレーキ／←→ ハンドル／C クルーズ／Esc メニュー）。

### 画面に表示される情報

- いまいる **都道府県・市区町村・町名**（県や市の境界を越えると「〇〇県に入りました」と表示）
- いま走っている **道路の名前**（例：「靖国通り」「国道1号」）
- 地図上の **道路の色分け**（緑＝高速道路、赤＝国道などの幹線、橙＝主要道路、黄＝県道クラス）と道路名・駅名・地名
- 最寄りの **ランドマーク** の方角と距離、目的地の方角と距離
- ミニマップ（北が上。タップで縮尺切替、通ってきた道を青線で表示）
- 移動距離と「**実時間換算**」の所要時間（倍速で移動しても、実際ならどれくらいかかるかが分かります）

## 景色について

- 地面：国土地理院の **航空写真（全国最新写真）**
- 建物：OpenStreetMap の建物データを高さ付きで **3D表示**
- 地形：標高データで **山の起伏** を表示（富士山なども立体的に見えます）
- 有名な建築物：東京タワー、東京スカイツリー、大阪城、名古屋城、姫路城、熊本城、松本城、首里城、通天閣、あべのハルカス、京都タワー、金閣寺、神戸ポートタワー、福岡タワー、さっぽろテレビ塔、横浜ランドマークタワー、厳島神社の大鳥居 は専用の立体モデルを配置。その他（国会議事堂、浅草寺・雷門、清水寺、原爆ドーム など）は名前の目印を表示します。

## 起動方法

ビルド不要の静的サイトです。インターネット接続が必要です（地図データを読み込むため）。

```bash
# このフォルダで簡易サーバを起動
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

スマホで遊ぶには、GitHub Pages などで公開するのが簡単です（リポジトリの Settings → Pages → Branch を選択）。
公開した URL をスマホで開き、「ホーム画面に追加」するとアプリのように全画面で遊べます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | 見た目 |
| `js/data.js` | 乗り物の性能・出発地・ランドマーク・都道府県 |
| `js/models.js` | 有名建築物の立体モデル |
| `js/style.js` | 地図の描き方（航空写真・道路・建物・地名） |
| `js/sprites.js` | 乗り物の絵 |
| `js/vt.js` | 道路データの読み取り（道路アシスト・道路名表示用） |
| `js/game.js` | ゲーム本体（操作・移動・カメラ・表示） |
| `vendor/maplibre-gl/` | 地図描画ライブラリ MapLibre GL JS（BSD-3-Clause） |

ランドマークや出発地は `js/data.js` に1行追加するだけで増やせます。
