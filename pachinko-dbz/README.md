# e ドラゴンボールZ 超覚醒（ファンメイド・パチンコシミュレーター）

ドラゴンボールZ（魔人ブウ編まで）をテーマにした、**個人で楽しむ用**のブラウザ版パチンコ台です。
`index.html` をブラウザで開くだけで遊べます（サーバー・外部ライブラリ不要。画像は使わず文字と図形で表現しています）。

> 実在の遊技機・メーカー・版権元とは関係ありません。スペックはすべて架空です。

---

## 遊び方

| 機能 | 内容 |
| --- | --- |
| **実戦** | 「ハンドルON」で左打ち開始。保留が貯まると変動し、リーチ・予告・ボタン演出が発生します。大当り後は **右打ち**（盤面の「右打ち➡」が点滅） |
| **当りまで早送り** | 抽選は1玉ずつ本物どおりに行い、当たるまで一瞬で進めます。当たった変動は演出付きで見られます（設定でOFF可） |
| **RUSH・時短終了まで** | RUSH／神龍チャレンジを一気に消化して結果画面を表示 |
| **100回転・1000回転早送り** | 途中で当たればそこで止まって演出を再生 |
| **倍速** | ×1〜×32（打ち出し速度・演出速度とも） |
| **演出スキップ** | 今の演出だけ飛ばす |
| **演出鑑賞** | リーチ・予告・保留色・ボタン色・プレミア・結果（当り/ハズレ）を自由に選んで再生。「名シーン全部見る」で全SP/SPSPリーチを連続再生 |
| **スペック** | 全振り分け・継続率・突入率・期待出玉・交換率別ボーダー・全演出の期待度（理論値）・収支シミュレーター |
| **記録** | 精算ごとに投資・回収・収支・回収率・回転数・初当り・RUSH・最大連チャン・仕事量を保存。累計集計／トータル収支グラフ／CSV書き出し |
| **設定** | 機種、**回転率（千円あたり＝釘の広さ）**、交換率、電サポ増減、アタッカー削り、**投資上限**、貸出単位、オートボタン、ハズレ短縮、止め打ち、音量 |

キー操作：`Space`/`Enter`＝PUSHボタン、`H`＝ハンドル、`F`＝当りまで早送り、`S`＝演出スキップ

### お金の扱い
- 1玉4円で貸出（1000円＝250玉）。持ち玉があればそちらを先に使います（持ち玉遊技）。
- 投資上限に達すると打ち出しが止まり、上限の追加か精算を選べます。
- 精算時の回収額＝持ち玉×交換率（端数切捨て）、**回収率＝回収額÷投資額**。
- 「仕事量」は通常時の1回転ごとの理論期待値（現金投資ベース）の積算です。
- 打っている途中の状態は自動保存され、ページを閉じても続きから再開できます。

### 大当り・RUSH
- 初当り3R：最終ラウンドで「超サイヤ人になれるか!?」昇格チャレンジ（ボタン）→ 成功でRUSH、失敗で神龍チャレンジ
- ラウンド中：Z名シーン回想が流れる
- 超サイヤ人RUSH：ラディッツ〜純粋ブウまでの敵とバトル。かめはめ波・ファイナルフラッシュ・魔閃光・気円斬・気功砲 等で撃破＝大当り。最終変動はラストチャンスボタン
- LT（ラッキートリガー）「ULTIMATE BURST」：虹演出・ベジット／超サイヤ人3
- 神龍チャレンジ：ドラゴンボールを集め、引き戻すと神龍降臨

## ファイル構成
```
index.html        画面
css/style.css     台・液晶演出・パネル
js/spec.js        スペック定義と理論値計算（継続率・期待出玉・ボーダー）
js/engine.js      抽選エンジン（1玉ずつの入賞抽選・保留・変動・ラウンド・早送り・シミュレーター）
js/effects.js     キャラ・名シーンリーチ・予告テーブル・変動プラン生成
js/stage.js       液晶描画・ボタン入力・演出ステップ
js/director.js    変動／大当り／RUSHの演出進行
js/board.js       盤面（釘と玉）のアニメーション
js/audio.js       効果音（WebAudio合成）
js/main.js        実戦ループ・設定・記録・スペック画面・演出鑑賞
```
